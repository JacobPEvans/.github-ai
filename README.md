# JacobPEvans/.github-ai

Reusable AI review, policy-gate, and agent automation workflows, with their shared actions, scripts, dogfood workflows, tests, and documentation.

Consumers invoke workflows from `JacobPEvans/.github-ai/.github/workflows/<name>.yml@v1`.

The reusable PR-Agent workflow applies the central review rubric in `pr-agent/rubric.toml`; see [the PR-Agent guide](docs/pr-agent.md).
